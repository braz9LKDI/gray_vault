# History

A repository's history refers to all the commits that have been made to it.

The `git log` command displays commit history. Optional flags customize the display output:

- The `--oneline` flag condenses each commit entry into a single line.

- The `--decorate` flag controls reference pointer visibility, accepting `short`, `full` or `no`.

- The `--graph` flag draws a text representation of branch structure.

- The `--parents` flag lists parent commit hashes alongside each commit hash.
