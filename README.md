# Gray vault

Notes on everything I have learned and have not been too lazy to write down.

This is my personal knowledge vault: notes about software engineering, math, statistics, books, courses, college and ideas that probably started as "I should write this down before I forget it."

The main idea is simple: I want control over my notes. That is why the vault is plain text, mostly Markdown, versioned with Git. No database hostage situation, no mystery binary format, just files. I write and connect them with [Obsidian](https://obsidian.md), but nothing here depends on it.

## How it is organized

| folder          | what lives there                                        |
| :-------------- | :------------------------------------------------------ |
| `00-inbox/`     | Notes I captured but have not placed yet.               |
| `01-areas/`     | Knowledge by topic: concepts, how-tos and references.   |
| `02-resources/` | Notes from one book or course each.                     |
| `99-archive/`   | Finished college semesters and other inactive material. |
| `templates/`    | Templates for new notes.                                |
| `docs/`         | How the vault works.                                    |

Source notes keep the context where I learned something; area notes keep the reusable knowledge, and links connect the two instead of copies.

## Contributing

Pull requests are welcome, as long as they follow the [style guidelines](docs/style_guidelines.md).

Useful contributions include:

- fixing typos.

- improving explanations.

- fixing broken links.

- correcting wrong information.

- suggesting better organization.

- pointing out questionable bullshit I wrote while half asleep.

This is a personal vault, so not everything is meant to be polished or universally useful, but improvements are appreciated.
