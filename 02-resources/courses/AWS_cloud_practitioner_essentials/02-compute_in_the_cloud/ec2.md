# EC2

Amazon EC2 stands for Amazon Elastic Compute Cloud. It is an AWS service that provides virtual servers in the cloud.

An EC2 virtual server is called an instance. Instances can be used to run applications, host websites, process data or support backend services.

With Amazon EC2, computing capacity can be launched when needed instead of buying and maintaining physical servers. Instances can be started, stopped, resized or terminated depending on the needs of an application.

When an EC2 instance is created, several choices are made, such as the operating system, instance type, storage, network settings and security rules. The instance type defines the amount of compute power, memory and network performance available.

Amazon EC2 is flexible because capacity can scale up or down. More instances can be added when traffic increases and fewer instances can be used when demand is lower.

The main idea is that Amazon EC2 provides resizable compute capacity in the AWS cloud through virtual servers called instances.
