# Amazon Lightsail

Amazon Lightsail is an AWS service designed to make it easier to launch and manage simple cloud projects.

Lightsail provides virtual private servers, also called **instances**, with a simpler setup experience than [[02-resources/courses/aws_cloud_practitioner_essentials/02-compute_in_the_cloud/ec2|Amazon EC2]]. It is commonly used for websites, web applications, small business applications, blogs and development environments.

Lightsail includes common cloud resources in one place, such as instances, storage, networking, DNS, snapshots, load balancers and managed databases. This makes it useful when a project needs a simpler and more guided AWS experience.

A Lightsail instance can be created from a blueprint. A blueprint is a preconfigured setup that can include an operating system or an application stack, such as WordPress, Node.js or LAMP.

Lightsail is often easier to start with than Amazon EC2 because it provides simplified configuration and predictable pricing. However, Amazon EC2 provides more flexibility, deeper configuration options and more control for complex architectures.

The main idea is that Amazon Lightsail is a simplified way to run cloud applications on AWS, especially when a project needs basic infrastructure without the complexity of managing many AWS services separately.
