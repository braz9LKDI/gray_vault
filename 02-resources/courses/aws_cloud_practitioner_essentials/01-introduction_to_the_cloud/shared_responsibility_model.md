# Shared responsibility model

The AWS shared responsibility model explains how security and compliance responsibilities are divided between AWS and the customer.

AWS is responsible for security of the cloud. This means AWS protects the infrastructure that runs AWS services, including hardware, software, networking and physical data centers.

The customer is responsible for security in the cloud. This means the customer manages the resources, data, users, permissions and configurations used inside AWS services.

The amount of responsibility can change depending on the type of service used. With some services, AWS manages more of the infrastructure. With other services, the customer has more control and more responsibility.

The main idea is that AWS secures the underlying cloud infrastructure, while the customer secures what is created, stored and configured in the cloud.
