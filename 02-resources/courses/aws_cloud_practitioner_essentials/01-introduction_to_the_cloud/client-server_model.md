# Client-server model

The client-server model is a basic way to describe how computers, applications and services communicate over a network.

A client is the part that sends a request. This can be a browser, mobile app or desktop application. A server is the part that receives the request, processes it and sends back a response.

In cloud computing, many services follow this model. Users, applications or devices send requests to cloud resources. The cloud resources respond by providing data, storage, computing power or other services.

The main idea is that the client asks for something and the server provides it.
