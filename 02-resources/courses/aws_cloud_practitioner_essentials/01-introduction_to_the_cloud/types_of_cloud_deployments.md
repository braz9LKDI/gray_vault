# Types of cloud deployments

Cloud deployments describe where cloud resources are located and how they are managed. Different deployment types are used depending on security needs, control requirements, cost and scalability.

There are three common cloud deployment models.

## Cloud-based

In a cloud-based deployment, applications and resources are fully deployed in the cloud. This means that servers, storage, databases and other services are managed through a cloud provider such as AWS.

## On-premises

In an on-premises deployment, resources are hosted in a physical data center managed by the organization. This model can provide more direct control over infrastructure but usually requires more maintenance, hardware and operational work.

## Hybrid

A hybrid deployment connects cloud resources with on-premises infrastructure. This allows some applications or data to remain in a private data center while other resources are used from the cloud.

---

The main idea is that cloud deployments define where infrastructure runs and how much responsibility is handled by the organization compared with the cloud provider.
