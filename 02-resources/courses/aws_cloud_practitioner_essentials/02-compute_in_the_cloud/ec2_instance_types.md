# EC2 instance types

Amazon EC2 instance types define the hardware profile of an EC2 instance. Each instance type provides a different combination of CPU, memory, storage and networking capacity.

Instance types are grouped into families. Each family is optimized for a different kind of workload.

1. General purpose instances: they provide a balance of compute, memory and networking resources. They are useful for applications that need a balanced amount of resources, such as web servers, development environments and small databases.

2. Compute optimized instances: they are designed for workloads that need strong processor performance. They are useful for batch processing, media transcoding, high-performance web servers and other CPU-intensive tasks.

3. Memory optimized instances: they are designed for workloads that process large amounts of data in memory. They are useful for high-performance databases, real-time data processing and caching.

4. Accelerated computing instances: they use hardware accelerators such as GPUs. They are useful for machine learning, graphics processing, video rendering and scientific workloads.

5. Storage optimized instances: they are designed for workloads that need fast access to large amounts of local data. They are useful for data warehouses, distributed file systems and applications with high read and write operations.

The main idea is that EC2 instance types make it possible to choose the right amount and kind of computing resources for the workload.
