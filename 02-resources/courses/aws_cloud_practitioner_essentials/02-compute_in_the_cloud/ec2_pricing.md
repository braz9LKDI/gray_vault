# EC2 pricing

Amazon EC2 pricing is based on the type of instance used, how long it runs, the selected region, the operating system, storage, data transfer and the pricing option selected.

The most common pricing options are on-demand instances, savings plans, reserved instances, spot instances and dedicated hosts.

## On-demand instances

On-demand instances allow compute capacity to be used without long-term commitment. This is useful for short-term workloads, testing, development or applications with unpredictable traffic.

## Savings plans

Savings plans provide lower prices in exchange for a usage commitment over a one-year or three-year term. This option is useful for workloads with steady or predictable usage.

## Reserved instances

Reserved instances provide a discount compared with on-demand pricing when a specific instance configuration is reserved for a one-year or three-year term.

## Spot instances

Spot instances allow unused EC2 capacity to be used at a lower price. This option is useful for workloads that can tolerate interruptions, such as batch jobs, data processing or testing.

## Dedicated hosts

Dedicated hosts provide a physical server dedicated to one customer. This option is useful for compliance requirements or software licenses tied to physical servers.

## Dedicated instances

Dedicated instances are Amazon EC2 instances that run on hardware dedicated to a single customer account. This option is useful when dedicated physical hardware is required, but direct control over the physical server is not needed.

Dedicated instances are different from dedicated hosts. With dedicated instances, billing is based on the instance. With dedicated hosts, billing is based on the physical host and there is more control over instance placement.

In short, dedicated instances provide dedicated hardware for EC2 instances without requiring management of the full physical host.

The main idea is that Amazon EC2 offers multiple pricing options so compute costs can be matched to workload needs, flexibility requirements and budget.
