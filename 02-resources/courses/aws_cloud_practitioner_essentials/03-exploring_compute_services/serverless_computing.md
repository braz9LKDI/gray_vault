# Serverless computing

Serverless computing is a cloud computing model where applications can run without managing the underlying servers.

The term serverless does not mean that servers do not exist. It means that the cloud provider manages the servers, infrastructure, scaling and availability. This allows more focus to be placed on the application code and business logic.

In AWS, serverless services automatically handle much of the infrastructure management. Resources can scale based on demand and costs are usually based on actual usage.

A common example is [[02-resources/courses/aws_cloud_practitioner_essentials/03-exploring_compute_services/aws_lambda|AWS Lambda]].

Serverless computing is useful for event-driven applications, backend services, automation tasks, data processing and applications with changing traffic patterns.

The main idea is that serverless computing allows applications to run without provisioning, managing or maintaining servers directly.
