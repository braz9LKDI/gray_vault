# Outposts

AWS Outposts is a hybrid cloud service that extends AWS infrastructure to an on-premises location, such as a data center, co-location space or local facility.

With AWS Outposts, supported AWS services can run locally while still using familiar AWS tools, APIs and operating models. This allows applications to use local compute and storage resources while remaining connected to an AWS Region.

An Outpost is the AWS-managed capacity installed at the customer site. AWS operates, monitors and manages the Outposts infrastructure as part of an AWS Region.

AWS Outposts is useful when workloads need low latency access to local systems, local data processing or data residency support.

AWS Outposts is part of a hybrid cloud approach because it connects on-premises infrastructure with AWS cloud services.

The main idea is that AWS Outposts brings AWS infrastructure and selected AWS services closer to local environments while still being managed through AWS.
