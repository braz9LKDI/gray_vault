# GitHub student pack learning platforms

- [Boot.dev](https://education.github.com/pack/redeem/bootdev-student): backend development, DevOps, data analysis, Python, Go, TypeScript and systems-oriented programming.

- [Codédex](https://www.codedex.io/github-students): beginner-friendly programming, Python, HTML, CSS, JavaScript, React, Git, GitHub and command-line basics.

- [DataCamp](https://education.github.com/pack/redeem/datacamp-student): data science, data analysis, data fluency, statistics, machine learning and data tools.

- [Educative](https://www.educative.io/github-students): web development, Python, Java, machine learning, hands-on coding labs and practical software engineering topics.

- [FrontendMasters](https://education.github.com/pack/redeem/frontendmasters-student): JavaScript, Node.js, frontend engineering, web development and advanced frontend architecture.

- [Scrimba](https://scrimba.com/github-education): interactive frontend development, JavaScript, CSS, React, Python, projects and coding challenges.

- [AlgoExpert](https://education.github.com/pack/redeem/algoexpert-student): coding interview preparation, algorithms, data structures and problem-solving patterns.

- [Interview Cake](https://education.github.com/pack/redeem/interviewcake-student): coding interview preparation, data structures, algorithms, practice questions and technical interview strategies.

- [GoRails](https://education.github.com/pack/redeem/gorails-student): Ruby, Rails, JavaScript, Hotwire/Turbo, Stimulus, Vue.js and web development.

- [SymfonyCasts](https://education.github.com/pack/redeem/symfonycasts-student): Symfony, PHP, backend web development, code challenges and framework-specific best practices.
